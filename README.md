# Stock Portfolio Tracker

A Java desktop application for managing and tracking a stock portfolio. The application allows users to record stock purchases, monitor portfolio performance, and retrieve current stock prices using Alpha Vantage API.

## Features
- Add/remove companies and stocks
- Track the amount of money invested in each stock
- Calculate portfolio profit and loss based on current stock prices
- Retrieve current stock prices using the Alpha Vantage API
- Save portfolio data using JSON
- Reload previously saved portfolio data between sessions
- Interactive desktop interface built with Java Swing
- Unit tests for core application functionality using JUnit

## Technologies
- Java
- Java Swing
- JSON
- JUnit
- Alpha Vantage API

## Running the Program
Ensure that Java is installed and run ```StockPortfolioTrackerUI.java```. The GUI will pop up in another window for the user to use.
